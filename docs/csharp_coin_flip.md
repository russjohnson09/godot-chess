# C# Coin Flip Example

## Purpose
This module provides a simple example of a coin flip program written in C#, complete with an interactive console user interface (UI) powered by `CoinGame` and unit tests demonstrating random generation of Heads and Tails under `csharp_coinflip`.

## How to Run
To run the interactive coin flip application:
```bash
dotnet run --project csharp_coinflip/csharp_coinflip.csproj
```
(Press Enter to flip the coin, or type `q` to quit).

## How to Test
To run the unit tests:
```bash
dotnet test csharp_coinflip/Tests/csharp_coinflip.Tests.csproj
```
