# C# Coin Flip Example

## Purpose
This module provides a simple example of a coin flip program written in C#, complete with unit tests demonstrating random generation of Heads and Tails.

## How to Run
To run the coin flip application:
```bash
dotnet run --project csharp_coin_flip/csharp_coin_flip.csproj
```

## How to Test
To run the unit tests:
```bash
dotnet test csharp_coin_flip_tests/csharp_coin_flip_tests.csproj
```
