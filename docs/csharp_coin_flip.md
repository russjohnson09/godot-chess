# C# Coin Flip Example

## Purpose
This module provides a simple example of a coin flip program written in C#, complete with unit tests demonstrating random generation of Heads and Tails under `csharp_coinflip`.

## How to Run
To run the coin flip application:
```bash
dotnet run --project csharp_coinflip/csharp_coinflip.csproj
```

## How to Test
To run the unit tests:
```bash
dotnet test csharp_coinflip/Tests/csharp_coinflip.Tests.csproj
```
