# Rust Coin Flip Example

## Purpose
This module provides a simple example of a coin flip program written in Rust, complete with unit tests demonstrating random generation of Heads and Tails.

## How to Run
To run the coin flip application:
```bash
cargo run --manifest-path rust_coin_flip/Cargo.toml
```

## How to Test
To run the unit tests:
```bash
cargo test --manifest-path rust_coin_flip/Cargo.toml
```
