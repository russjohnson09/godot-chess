Steps to Install:
1. Download and run rustup-init.exe:
Go to rustup.rs (https://rustup.rs/) and download rustup-init.exe (or run the PowerShell command below).
2. Run via PowerShell (Recommended):
Open PowerShell and execute the official installer script:
winget install Rustlang.Rustup
(Alternatively, you can download rustup-init.exe from rustup.rs and run it directly).
3. Follow the Prompts:
The installer will default to standard installation (option 1), which installs the latest stable version of Rust, rustc, and cargo.
4. Restart Terminal:
Close and reopen your terminal (PowerShell, Command Prompt, or Git Bash) so that Cargo is added to your system PATH.
