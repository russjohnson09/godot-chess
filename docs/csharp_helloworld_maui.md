# C# .NET MAUI Hello World GUI Example

## Purpose
This module provides a basic hello world graphical user interface (GUI) written using .NET MAUI (`csharp_helloworld_maui`). It features a text label that displays "Hello, World!".

## How to Run / Build
To build the .NET MAUI hello world application:
```bash
dotnet build csharp_helloworld_maui/csharp_helloworld_maui.csproj
```

To build and publish an executable / output binaries:
```bash
dotnet publish csharp_helloworld_maui/csharp_helloworld_maui.csproj -c Release
```

## How to Test
To run the unit tests:
```bash
dotnet test csharp_helloworld_maui/Tests/csharp_helloworld_maui.Tests.csproj
```
